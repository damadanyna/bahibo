# Projet Bahibo

## Stack

- Flutter frontend
- FastAPI backend
- MySQL
- SSE streaming
- Vuetify admin panel

## Architecture

- component/ui = composants réutilisables
- page/navigation = pages principales
- backend/controller = logique métier
- backend/sql = requêtes SQL

## Conventions

- éviter la duplication
- privilégier les services
- toujours utiliser async/await
- ne jamais casser les modèles JSON existants
- respecter architecture modulaire

## Objectifs

- performance mobile
- réduction consommation API
- UI fluide
- architecture scalable

## Règles importantes

- ne jamais supprimer une fonctionnalité existante
- toujours proposer optimisation avant refactor massif
- privilégier modifications minimales
- commenter les changements critiques
