CHECKLIST QA BANAY
Version: 2026-06-01
Usage: document a envoyer aux testeurs remuneres

Instructions pour le testeur
- Appareil: indiquer modele, version Android, qualite reseau (bon/moyen/faible)
- Build testee: indiquer version APK
- Pour chaque anomalie: joindre capture ecran ou video courte
- Si un test echoue: remplir la colonne "Bug observe" et proposer une priorite
- Priorite:
  P0 = blocant, impossible de continuer
  P1 = majeur, fonctionnalite cle tres degradee
  P2 = moyen, contournement possible
  P3 = mineur ou cosmetique
